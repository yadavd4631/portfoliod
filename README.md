# Deepak Yadav — DevOps Engineer Portfolio

Personal portfolio of **Deepak Yadav**, a DevOps Engineer specializing in AWS cloud infrastructure, Kubernetes/EKS, Terraform, and Datadog observability.

🌐 **Live Site**: [portfolio-deepaky.vercel.app](http://portfolio-deepaky.vercel.app)

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Analytics & SEO**: Vercel Analytics, `next-sitemap`

---

## 📁 Repository Structure

```
portfoliod/
├── app/
│   ├── layout.tsx         # Metadata, fonts, and root layout
│   ├── page.tsx           # Main single-page portfolio layout
│   └── globals.css        # Global styles & Tailwind
├── components/
│   ├── IntroScreen.tsx     # Visitor counter & animated intro
│   ├── about-section.tsx   # Bio, social links & resume download
│   ├── Experience.tsx      # Work experience timeline
│   ├── Certifications.tsx  # Datadog certifications
│   ├── Skills.tsx          # Categorized cloud & DevOps skills
│   ├── Projects.tsx        # Featured projects & architecture
│   ├── Education.tsx       # Academic background & coursework
│   ├── Contact.tsx         # Contact links & email
│   └── Footer.tsx          # Footer
└── public/
    ├── resume.pdf          # Latest resume PDF
    ├── robots.txt          # SEO crawler config
    └── sitemap.xml         # Site map
```

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site in the browser.

### Production Build

```bash
npm run build
npm run start
```
